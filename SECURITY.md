# Security Policy

This is a small reference template with no runtime dependencies and no
deployed service, so the attack surface is limited to the CI pipeline
itself (the pinned GitHub Actions and the actionlint download).

## Reporting a vulnerability

If you find a supply-chain issue (an unpinned action, a compromised
dependency, or a workflow permission that's broader than it needs to
be), please open a private security advisory via GitHub's "Report a
vulnerability" button on the Security tab rather than a public issue.
